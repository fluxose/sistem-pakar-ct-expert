   # Sistem Pakar Reaksi Media Kontras CT-Scan

   Sistem pakar penentuan tingkat reaksi media kontras pada CT-Scan
   dengan metode Certainty Factor. Sumber pengetahuan: wawancara dengan
   Agung Anugrah, Amd.Rad (RS Mitra Husada Pringsewu).

   ## Teknologi
   HTML, CSS, JavaScript | Python (Flask) | MySQL

   ## Cara Menjalankan
   1. Jalankan MySQL (XAMPP), impor `backend/schema.sql` lewat phpMyAdmin
   2. `cd backend` lalu `pip install -r requirements.txt`
   3. `python app.py`
   4. Buka http://127.0.0.1:5000

   ## Pengujian
   `cd backend` lalu `pytest -v`

   ## Catatan
   Sistem ini alat bantu; keputusan akhir ada pada radiolog/dokter.
